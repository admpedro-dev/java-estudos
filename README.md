# Estudos da linguagem Java

Caderno de estudos em Java: exercícios organizados por tema, de lógica e POO a coleções, streams e JDBC. Baseado no curso Maratona Java de autoria do DevDojo + exercícios próprios.

**Status:** em andamento.

## Como rodar

Abra o projeto no IntelliJ IDEA (JDK 21 ou superior) e execute o `main` da classe desejada.
